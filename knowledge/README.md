# Carpeta de conocimiento de CORT

Poné aquí tus apuntes en `.md`, `.txt` o `.rst`. CORT los lee por párrafos (separados
por una línea en blanco) y los consulta con «qué sabes de …».

Sugerencias:

- Un archivo por materia: `morfo-3.md`, `bioquimica.md`, `horarios.md`.
- Escribí los temas como títulos (`## Ciclo de la urea`) para que el fragmento
  encontrado tenga contexto.
- Este README se ignora a propósito en las búsquedas.

Nada de aquí sale de tu equipo: la búsqueda es local y por palabras clave.
